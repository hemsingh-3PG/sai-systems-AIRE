1
What this is

A picture of all production in the “Microsoft Azure” subscription: which website sends work to which server, which database it uses, which outside companies it talks to, and how the network is protected. Built from the live Azure configuration plus the connections recorded by Application Insights. Pre-prod, staging, UAT, QA, dev, test and demo are deliberately left out. Resource names use <e> for the environment code (<E> in upper-case names); this map was captured from production, where <e> = p.

3
Colours

Each box carries its product colour on the left edge. Line colour shows the type of connection: SQL, Service Bus, Blob, Key Vault or HTTP. Dashed lines are Front Door routes from configuration; dotted lines are browser calls.

4
Using the map

In Explore one app, type or pick an app: what sends it work is on the left, what it uses is on the right. Click any box to move to it; “← Back” returns. Words you don’t know are in the glossary.
